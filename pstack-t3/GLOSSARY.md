# pstack in T3 Code

Language for personal model selection and independent review.

## Language

**Worker default**:
The model and starting reasoning effort used for delegated work unless a more specific role or explicit user instruction takes precedence.

**Reasoning budget**:
A named preset for the starting reasoning effort of roles without an explicit effort preference.
_Avoid_: Model budget

**Independent review**:
An assessment of an artifact by a fresh agent that did not produce it. The chosen reviewer belongs to a different model family from the author.

**Panel**:
A group of agents assigned to generate or assess alternatives within one pstack task.
