## Maestría skills

Maestría’s `.claude/skills/` entries point to `.agents/skills/`. The two vault workflow entries load the canonical skills in `copilot/skills/`. Resolve their relative links in that vault layout, where the companion skills and `00-System/` files live. This repository keeps reference copies of the workflows.

- [vault-ingest](vault-ingest/SKILL.md) imports selected material into Maestría. Source folder in Maestría is `copilot/skills/vault-ingest/`.
- [vault-connect](vault-connect/SKILL.md) links checked sources to concept notes. Source folder in Maestría is `copilot/skills/vault-connect/`.
- [obsidian-cli](obsidian-cli/SKILL.md) works with a running Obsidian app. It is adapted from Maestría’s `.agents/skills/obsidian-cli/`.
